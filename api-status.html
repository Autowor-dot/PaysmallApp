Endpoint reachability

Each endpoint is called the way the frontend calls it. A JSON reply, even "401 Please log in", proves the connection works. A non-JSON reply means PHP is not executing (static hosting, wrong path, or a fatal error).

Go-live checklist

  1. Upload the whole project to the web root so pages and api/ share the same origin (needed for session cookies).
  2. Set the database credentials, a unique install_key and webhook_secret in api/config.php (or api/config.local.php).
  3. Open api/install.php?key=YOUR_INSTALL_KEY once to create the tables, then re-run these checks: every table should show as present.
  4. Register at register.html, log in, and confirm the Session card above turns green.
  5. Point your Mobile Money / bank provider's callback at api/payment-webhook.php with the X-LipaLink-Signature header set to your webhook secret.
  6. Set app_env to production before launch so the payment simulator and reset-link preview are disabled.
